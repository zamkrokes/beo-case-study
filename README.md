# BEO Case Study

Day-ahead 15-minute load forecast for a single German C&I site, supporting battery peak-shaving decisions.

## Running it

```css
pip install -r requirements.txt
python main.py
```

Place `load_timeseries_2025_case_study.csv` in `data/`.

`load_forecasting_p95.ipynb` contains the full exploration and analysis.
